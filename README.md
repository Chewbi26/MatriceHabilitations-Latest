# Matrice d'Habilitations

Application web autonome de gestion des habilitations informatiques : un seul fichier HTML, sans serveur ni ressource Internet. Elle ne contient aucune donnée : elle ouvre le fichier de données (`.json`) de l'établissement, rangé sur son réseau.
